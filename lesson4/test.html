Lesson 4: Line Graphs

Glossary Terms

Line graph

A graph that uses plotted data points and lines to make a pattern or trend easier to see.

X-axis

The horizontal axis. In this fair test it shows the independent variable — what was changed.

Y-axis

The vertical axis. In this fair test it shows the dependent variable — what was measured.

Coordinate

A pair of values that tells us where one data point belongs on a graph.

Trend

The overall pattern in how the measured values change.

Reasoned prediction

A prediction that uses scientific knowledge to explain what you expect to happen.

Lesson 4 · Line Graphs

Reading the Story in Fair-Test Data

Scientists use line graphs to turn measurements into a visual pattern. In this lesson, you will learn how to label the axes, plot data accurately and use the finished graph to decide what the results mean.

Learning objective

We are learning how to represent fair-test data in a line graph.

Success criteria

  1. I can identify what belongs on the x-axis and y-axis.
  2. I can label axes with the variable and unit and plot data points accurately.
  3. I can use a line graph to describe a pattern or trend and judge a prediction.

Think like a scientist

One dataset, a clearer story

A table stores the measurements. A line graph helps us see how the measured result changes as the independent variable changes.
