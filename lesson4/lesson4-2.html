Lesson 4 · Bar Graphs

Glossary Terms

Graph

A visual way of showing data so patterns, comparisons and relationships are easier to see.

X-axis

The horizontal axis. In a fair test line graph, this often shows the independent variable — what was changed.

Y-axis

The vertical axis. In a fair test graph, this often shows the dependent variable — what was measured.

Line graph

A graph that uses points and lines to show how a measured value changes across ordered or continuous values.

Bar graph

A graph that uses separate bars to compare amounts across different categories.

Lesson 4 · Part B

Using Bar Graphs to Visualise Data

Bar graphs help scientists turn fair-test data into a visual comparison, making patterns and differences between categories easier to see.

Learning objective

We are learning how to represent fair test data in a bar graph.

Success criteria

  1. I am learning how to collect and visualise data.
  2. I can label axes and plot data points on a bar graph.
  3. I can use a bar graph to analyse the results of a fair test.

Think like a scientist

Constructing a bar graph

How to construct a bar graph to represent fair test data:

1
The independent variable is on the x-axis The independent variable — the thing I change — is found in the left-hand column of a fair test table. The x-axis runs along the bottom of the graph.
2
The dependent variable is on the y-axis The dependent variable — the thing you measure — is found in the column to the right of the independent variable. If the test was repeated, use the average measurement.
3
Plot the point for each row in your table Find the x-axis value and draw a dotted line upwards. Find the y-axis value and draw a dotted line across. Where the lines meet, place an x to mark the spot.
4
Draw a bar for each plotted point Keep every bar the same width and leave the same amount of space between each bar.

Using bar graphs

Visualising fair test data

Scientists use a bar graph when they want to visualise discrete or categorical data.

A bar graph organises information using bars of different lengths. This makes patterns in fair-test data easier to see: a longer bar shows more, while a shorter bar shows less.

Less
More

Discrete data

Discrete data uses whole-number values such as 1, 2 and 3. When you are counting whole objects, there are no values in between.

1 2 3

Examples: number of pages in a book, number of pets.

Categorical data

Categorical data is sorted into different groups or categories.

Hair colour Favourite animal Type of pet

Examples: hair colour, favourite animal, types of pets.
