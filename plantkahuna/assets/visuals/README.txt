CANVA VISUAL ASSETS
===================

Export individual elements as transparent PNG or WebP files here.
Then open scripts/plantkahuna_scripts/plantkahuna.js and fill in the
appropriate filename inside VISUAL_ASSETS.

Example: beakers: { "150": "beaker-150.png", "300": "beaker-300.png" }

This folder is intentionally empty in the prototype.
See the root README.md for all supported image slots and alignment tips.
