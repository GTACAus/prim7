Glossary Terms

Data

The observations or measurements you collect during an investigation. Data can be numbers (e.g. temperature, height) or descriptions (e.g. colour, texture).

Units

The standard amount or portion of something that is measured, e.g. cm for length, kg for weight, minutes for time.

Table

An organised arrangement of columns and rows used to display data.

Repeat tests

The same test carried out two or more times under exactly the same conditions, to check that your results are consistent.

Independent variable

The one variable changed during a fair test experiment.

Dependent variable

The result that is observed or measured during a fair test experiment.

Think like a scientist

The Fair-Test Formula

A fair test experiment helps us to find out if changing one thing causes a measureable effect in another thing.

1
Change one factor Choose the independent variable.
2
Measure the effect this causes Measure the dependent variable.
3
Keep everything else the same Control all other variables.

Think like a scientist

Scientific Table Formula

When scientists carry out fair tests, they use tables to record data. This helps them to see patterns, trends, and relationships in the data.

1
The independent variable and how you will change it This goes in the left-hand column of the table
2
The dependent variable and the measurements you make Put in the column to the right
3
Repeat each test three times Record each repeat as test 1, test 2, and test 3. This helps you to spot errors should they occur

Why repeat each test 3 times?

In a fair test experiment, we repeat each test 3 times using the same conditions.

We do this to:

  • Check for mistakes when setting up each test.
  • Check for errors when making measurements.
  • Spot any strange results.
  • Make the results more reliable and trustworthy.

Why is it important to repeat a test 3 times?

What would happen if you only did the first test?

Repeating a test helps us check whether the results are consistent and makes it easier to spot mistakes or unusual results. If we only used one result, that result might be unusual or affected by an error, so our conclusion could be misleading.
