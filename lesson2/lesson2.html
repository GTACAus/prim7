Lesson 2: Planning a Fair Test Experiment

Glossary Terms

Variable

An aspect of an investigation that can be different or can change.

Independent variable

The one variable changed during a fair test experiment.

Dependent variable

The result that is observed or measured during a fair test experiment.

Controlled variables

The variables kept the same so the experiment is fair.

Fair test Experiment

An experiment where one variable is changed, one is measured, and all others are kept the same.

Success criteria

  1. I can identify variables in a fair test.
  2. To plan a fair test, I can select:
    • The independent variable (thing I change),
    • The dependent variable (thing I measure) and
    • The controlled variables (things I keep the same)
  3. I can use a diagram to describe my fair test

Think like a scientist

The fair test rules

Use a fair test to find out if changing one thing causes an effect in another thing.

1
Change one factor Choose the independent variable.
2
Measure the effect this causes Measure the dependent variable.
3
Keep everything else the same Control all other variables.

Using variables to design a fair test

In a fair test, you change one variable and measure the effect this causes on another variable. You keep all other variables the same.

Change

Independent variable

Does this cause an effect on another variable?

Measure

Dependent variable

To observe the effect cause by the thing you change.

Keep the same

Controlled variables

Be sure that the effect you measure can only be caused by the thing you measure.

We write a testable question to show what is changed and what is measured in a fair test.
