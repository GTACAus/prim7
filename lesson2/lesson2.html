Lesson 2: Planning a Fair Test Experiment

Glossary Terms

Variable

An aspect of an investigation that can be different or can change.

Independent variable

The one variable changed during a fair test experiment.

Dependent variable

The result that is observed or measured during a fair test experiment.

Controlled variables

The variables kept the same so the experiment is fair.

Fair test Experiment

An experiment where one variable is changed, one is measured, and all others are kept the same.

Think like a scientist

The fair-test formula

A fair test experiment helps us to find out if changing one thing causes a measureable effect in another thing.

1
Change one factor Choose the independent variable.
2
Measure the effect this causes Measure the dependent variable.
3
Keep everything else the same Control all other variables.

Why are variables important when planning a fair test experiment?

A fair test experiment is a scientific experiment that you use to investigate a testable question. In a fair test experiment, only one variable is changed, only one variable is measured, and all other variables are kept the same.

A fair test experiment starts with a testable question. Testable questions are written to show the variable you are changing and the variable you will measure.

Change

Independent variable

The variable you change, the cause, is called the independent variable.

Measure

Dependent variable

The variable you measure, the effect, is called the dependent variable.

Keep the same

Controlled variables

In a fair test experiment, all other variables must be kept the same. They are called controlled variables.

In a fair test experiment, one variable is changed, one is measured, and all other variables must remain the same.

Why is it important that we change only one variable and keep all other variables the same in a fair test experiment?

Click the button below to check your answer.

Only changing one variable allows you to know that no other variable has affected the results of the test. Any effect or result you measure in the dependent variable is caused by the thing you changed (the independent variable).
