Lesson 2: Planning and Conducting a Fair Test

Glossary Terms

Variable

An aspect of an investigation that can be different or can change.

Independent variable

The one variable changed during a fair test.

Dependent variable

The result that is observed or measured during a fair test.

Controlled variables

The variables kept the same so the experiment is fair.

Fair test

An experiment where one variable is changed, one is measured, and all others are kept the same.

Think like a scientist

The fair-test formula

A fair test helps us to find out if changing one thing causes a measureable effect in another thing.

1
Change one factor Choose the independent variable.
2
Measure the effect this causes Measure the dependent variable.
3
Keep everything else the same Control all other variables.

The three types of variables

Scientists give different names to the variable they change, the result they measure and the other variables they keep the same.

Change

Independent variable

The one variable that is changed. This is the possible cause.

Measure

Dependent variable

The effect or result that is observed and measured.

Keep the same

Controlled variables

Everything else that must stay the same so the test remains fair.

A fair test changes one variable, measures one result and keeps all other variables the same.
Stop and Think

Why is it important that we change only one variable and keep all other variables the same in a fair test.

Only changing one variable allows you to know that no other variable has affected the results of the fair test. Any effect or result you measure in the dependent variable is caused by the thing you changed (the independent variable).
